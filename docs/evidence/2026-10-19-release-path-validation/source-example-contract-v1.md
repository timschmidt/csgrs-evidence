# Documented source-checkout example

The README explicitly documents the unreleased source checkout. Build its exact
examples/basic.rs with Cargo, default features and the original workspace config,
then execute the frozen binary in an isolated output directory. Source, compiler,
policy, parameters and fixtures remain unchanged. This is source-checkout evidence,
not a clean registry install; the failed external version resolution stays failed.

Read the emitted binary STL through the public importer, inspect the missing
source history and projection flags, and require separate certified PWN and
manifold checks. Reuse the unchanged E97 exact rational cell oracle and affine
fixtures to prove equality with [0,12]^3 minus [4,8]x[4,8]x[-2,14], then consume
the imported mesh in a union with canonical empty and repeat the set proof.
Export/import a bound artifact and check the summary remains qualified, with
another exact set and topology check. This verifies the source quickstart and
format semantics without pretending that plain STL recovers earlier history.
Record serialization bytes separately from semantic equality.

Keep the E100 storage/log/8 GiB limits, Cargo jobs 2, 1800-second build limit and
60-second runtime/inspection limits. The source checkout is read-only. Preserve
the two completed package targets and the failed target. No public availability,
complete provenance, full runtime corpus or release-ready claim follows.
