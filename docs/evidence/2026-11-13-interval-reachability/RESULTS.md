# Qualified finite endpoint covers

Source commit: `404ba07ecdeeab8838836df0bc6b36bc78401b20`, parent
`5e308fb8c9e84550a4149bd517ecddaf36c52cc1`. Fifteen source/test/documentation
paths add optional reachability over the existing expression-field domain and
exact dyadic Cartesian subdivision/regridding. The target is plan 10.8 and the
phase-12 baseline, not completion of the fifteen-phase goal.

The accepted contract is a finite endpoint union C with
R subset C subset R + [-epsilon,epsilon]^N at the exact end time. The source,
partition, all attempts and native proofs remain retained. Only whole-request
completion, identity or successful empty expose a cover. See CONTRACT.md and
REVIEW.md for ownership, soundness, explicit native-prefix transport, scope and
resource exclusions. The original uncertain Riccati fixture is preserved at
depth 8, maximum 2048 whole attempts, default 256 segments per attempt and
1/128 epsilon. Its earlier depth, coefficient-growth and step-limit failures
are retained, along with the rejected or adverse implementation experiments.

Independent acceptance expectations include rational constant flows, exact closed
partitions, an exponential Taylor sum with a bounded tail, and nonlinear Riccati

source replay in fresh processes, explicit outward transport and rational
reconstruction of the new proposal provenance. A finite corpus is not a universal
successful-termination or closure proof.

2,944,283 allocations and 185,257 reallocations, requesting 252,292,136 cumulative
bytes (reallocation requests count their whole requested size). A separate

The stress report's large retained evidence is a practical limitation, not hidden
by reporting only the endpoint boxes. The new full-work observer is 4,167,672 ELF
bytes with a 2,195,096-byte function union; these absolute sizes are not a comparison
to a different legacy contract. Retention-observer timing rows are not used for
performance claims.

No whole-heap, CPU, wall-clock or excluded scalar-refinement bound is claimed.
Zero epsilon, coarse grids and arbitrary fields/horizons need not complete.
Taylor/wrapping methods, broader adoption, physical-clock cover convenience,
platform/HIL qualification, release work and the pending extraction remain open.
