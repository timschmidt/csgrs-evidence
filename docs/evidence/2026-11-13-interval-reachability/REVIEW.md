# Source review of the finite-cover increment

The exact source field, its binding and the original initial set remain authoritative.
A positive-horizon accepted leaf has a concatenation of existing Picard existence
certificates. Every native prefix starts at the previous certified end time, with
an outward regridded endpoint whose inclusion was checked. The last transport,
positive progress and exact horizon comparison precede success. Native one-step
limits remain typed stopped requests; the outer report explicitly consumes only
their certified prefixes. No stopped outer report exposes a whole cover.

Exact closed initial bisections preserve the union, including their shared facet.
Each nonempty leaf contains an original initial point with a certified trajectory.
Its endpoint lies in the leaf endpoint box. When that box's infinity diameter is
at most epsilon, each point of the box lies within epsilon of that reachable
endpoint. Thus the complete union both contains the reachable set and lies in its
stated infinity-norm thickening. This is a set-distance guarantee, not a pairing
of every enclosure point with the same initial condition. Identity and empty
requests retain exact set semantics without an unnecessary diameter condition.

Displacement-width padding is an untrusted proposal, explicitly tagged with its
source attempt. It never bypasses the Picard authority. The fixed old native
strategy retains its predicate ordering, original padding temporary lifetime and
result vocabulary. Source reconstruction, not a serialized success flag, owns
replay. Tests independently reconstruct new padding from rational endpoints and
compare nonlinear reachable fibers to x/(1-x/2). The affine point case uses a
rational Taylor sum with an independently bounded geometric tail.

All nested integrations spend one shared graph/scalar budget. Cell, depth,
whole-attempt and time-refinement limits are explicit. Each whole attempt has at
most max(1, maximum_steps) native searches; each native search retains its own
bounded expansions/halvings. Entry-capacity checks precede retained vector growth.
Resource failures and cancellation do not become a partial success. The original
accounting exclusions remain: these counters do not provide a whole-heap,
wall-clock, total CPU or scalar-refinement bound. Ordinary allocator failure is
not newly claimed to be recoverable. Successful zero-epsilon search is not
promised, nor is termination with a successful cover for arbitrary admitted
fields, singularities, times or grids.

This implements finite endpoint covers for the existing dyadic expression-field
search. It does not finish Taylor models, demand-driven sparse coefficients,
wrapping reduction, hybrid guards, physical-clock cover wrappers, general stack
adoption or release/platform qualification. Existing rational-clock users may
explicitly consume the normalized field in its declared time coordinate.
