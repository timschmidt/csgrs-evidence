## Observed gate and retained scope

The minimal sensitivity prototype passed its uncertain-shear witness. The old
release comparison then failed: flow_noise +800 raw bytes / +496 text bytes;
qr_coordinates +24 raw bytes / unchanged text. Symbol evidence attributes the
flow_noise text growth to Debug/drop monomorphizations. No arbitrary layout or
inlining retry is justified. The prototype is retained only in this experiment's
rejected-prototype directory; it is not implemented support and did not complete
the planned sensitivity corpus. Existing dynamics source is restored exactly.

The independent retained extension is IntervalMatrix::scale in Hyperlattice's
own matrix arithmetic (plan Phase 6), using the existing backend multiplication
and shared fallible-array constructor. Domain: each admitted scalar family,
rectangular matrices, explicit empty and zero-dimensional unit sets. It encloses
each entry times one scalar interval and forgets inter-entry correlations, as
other Cartesian matrix operations do. It consumes one shared native context in
row-major order, propagates typed overflow/size/work errors, and introduces no
new predicate dispatch, source-policy choice or approximation terminal.

Acceptance adds independent endpoint oracles across all families, generated
matrix product -> scale -> matrix/vector product, fractional fixed rounding and
resource failures/retry, all empty/unit cases, primitive zero allocations, and
fresh-process matrix replay followed by another operation. Scalar-family
validation and original malformed replay cases remain unchanged. There is no
new cancellation promise: matrix scaling inherits the scalar context's existing
cooperative boundaries. The native dyadic context has no cancellation token.
Retained logical shape is R*C; scalar payload, heap and backend resource limits
retain their current contracts. Existing downstream release binaries, outputs,
dispatch and performance gates still apply after removing the prototype.
