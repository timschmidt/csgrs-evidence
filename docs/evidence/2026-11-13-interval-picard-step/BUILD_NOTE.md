The first external Picard probe build reused the baseline library because shutil.copy2 preserved source timestamps older than the baseline build. No timings were taken from that failed build. All copied candidate source paths were touched, then rebuilt. Qualification and artifact capture use the rebuilt candidate.
The external cost probe also needed an explicit N=1 annotation for its empty case. Its first run incorrectly expected a scalar budget of 16 to exhaust an empty-state step; that step completes with less work. The probe now uses measured required work minus one for the boundary rejection, retaining budgets 0 and 1, and preserves the original failing log. Production code/tests were unchanged.
