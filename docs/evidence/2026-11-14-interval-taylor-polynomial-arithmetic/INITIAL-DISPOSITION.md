# Initial unisolated candidate rejected

The first seven-path candidate passes ten new admission tests and the existing
Taylor/affine fixtures but increases the maintained old Taylor-model cost consumer
from 3,920,800 to 3,929,000 bytes (+8,200). Several all-feature owner artifacts also
grow; all measurements remain in control-artifact-comparison.json. The field-only
consumer is byte-identical. No timing acceptance is inferred from artifact sizes.

This initial variant is not retained. The next variant isolates the new arithmetic
behind taylor-polynomial, forwards it explicitly in Hyperdynamics, and keeps the
legacy TaylorAffineRange in its original module. Only its private field visibility
widens to the parent for shared construction; layout, name, getters and public
access remain unchanged. Compare existing consumers and the previously existing
owner feature set unchanged. New-feature benchmarks separately qualify the added
completed polynomial-map contract; full-release feature-matrix work remains open.
