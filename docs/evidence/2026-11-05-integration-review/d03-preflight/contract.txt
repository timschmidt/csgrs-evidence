Owner: SynapsCAD evaluator/comparison harness; reuse openscad-rs, CurveRegion2,
SolidExpr and Hypermesh. Properties P17-P20, P25-P30, P34-P39. This is a
comparison tool, never a replacement geometry kernel or an approximate modeling
fallback.

Input domain: every .scad file in the parser's pinned OpenSCAD corpus

not a missing case. Use fresh native evaluator per case and complete separate

Native side: evaluate through the existing SynapsCAD parser/evaluator and keep
native Shape/CurveRegion2/TriangleMesh. Collect every failed part before any
comparison. Normalize top-level material with the evaluator's existing implicit
union/first-dimension semantics, retaining warnings and certainty. Do not use
Bevy display positions, replacement normals, or STL coordinates as native
source. Unsupported/unhandled syntax or warned partial evaluation must remain
visible; absence of triangles is not automatically proof of intended emptiness.

Interchange must have an explicit model boundary. OpenSCAD's OFF/SVG exports
project its floating geometry to decimal tokens; no fidelity/error bound to the
original source is assumed. Exact equality, where computed, is only relative
to that declared exported polygon/mesh model and the retained native result.
An exact imported model does not upgrade original source fidelity. OFF-to-OBJ
may translate syntax and unchanged coordinate tokens/indices only, delegating
triangulation/validation to the existing CSGRS importer. Nonplanar rounded
faces, malformed references and invalid PWN topology remain typed. No tolerance
welding, zero substitution, fitting or skipped face is permitted.

OpenSCAD SVG encodes closed boundary paths with fill=none. Standard SVG import
therefore does not mean a filled OpenSCAD region. An explicit OpenSCAD-boundary
adapter must assemble the closed contours under the declared NonZero material
semantics using CurveRegion2, and transport SVG y-down to world y-up exactly.
Open paths or unsupported syntax fail. Independent holed-square controls must
check outer/hole membership, complete set differences and traversal, not merely
area or box/count agreement.

Required witnesses: independently specified through-holed cube (volume24,
bounds[0,3]^3) and square (area8, outer[0,3]^2,hole[1,2]^2), canonical empties,
invalid paired with empty, unsupported modules/import context, decimal/near
coincidence, mixed dimensions, and actual timeout/memory controls. Observe
$preview mode and source definitions rather than changing hard cases.

Output statuses stay separate: exact equality relative to the declared export,
proved difference of those represented sets, import/validation failure,
unsupported/undecided native decision, incomplete native evaluation, invalid
input, panic/crash, and reached external containment. Bounding boxes, counts,
area/volume, or shared-wrapper agreement alone never certify intended set
identity. Every case and every difference needs a retained row and triage;
precision/tessellation/configuration differences are not silently accepted.
External limits are resource controls with units and an actual reached-limit
receipt, not mathematical completeness bounds or evidence of exact completion.
