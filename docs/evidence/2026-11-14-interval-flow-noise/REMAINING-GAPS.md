# Remaining goal scope

No phase or full implementation goal is complete in this stage.

- The flow-noise API takes explicit proposed steps and capacity; it does not
  implement an automatic horizon controller or a general algorithm portfolio.
  Longer nonzero-dimensional chains, wider nonlinear fields, mixed strategies,
  other hardware and competitive external validated-ODE engines need additional
  completed-workload evidence. The constant control remains materially slower.
- Existing scalar refinement, coefficient payload/CPU, total heap and native
  interruption exclusions remain. A graph budget is not a uniform resource
  guarantee. Some first-use requested allocations remain after source disposal,
  up to 312 bytes in this corpus; no leak-freedom claim is made.
- Phase7 generic solver migrations and Phase8 machine-profile ingress candidates
  remain cost-rejected. Do not repeat their diagnostics without a supported new
  hypothesis. Positive arithmetic and named budget work remain.
- Clock/Q30/servo changes and five Xtensa links remain retained; flash fit,
  stack/cycles and HIL remain open.
- The 41 staged dynamics extraction paths remain unaccepted on cost. The latest
  layout recheck reproduced the same binaries and six failures; unavailable
  hardware counters and noncausal simulation do not justify speculative layout
  changes or another identical campaign.
- Wider interval consumers, automatic native subdivision/monotonicity/interval
  Newton integration, deeper wrapping/coordinate adoption and full contracts
  throughout the plan remain open.
- Seven-crate archive-only docs and the flow-noise client passed here; the
  maintained 21-crate release script still builds workspace documentation,
  omits arbitrary docs.rs rustdoc arguments and resolves external lockfiles
  separately. Optional Hypervoxel publication, HyperBrep release, complete
  feature/platform/bindings/browser/HIL and reproducible dependency-resolution
  qualification remain open. No full pre-push matrix or publication occurred.
