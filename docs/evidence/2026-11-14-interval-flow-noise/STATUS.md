# Correlated endpoint transport qualification

The optional Hyperdynamics `flow-noise` API retains an affine outer endpoint
set and its shared proof history through explicitly proposed trajectory Taylor
steps. It reuses the existing Picard/trajectory authority and Hypersolve's finite
composition, parameter Taylor remainder, affine map and noise-column selection.
The earlier Cartesian shear-cancellation loss is reproduced and retained as an
adverse control. No old production function body or predicate order changes.

Each current affine set is a conservative superset of reachable states, not an
exact reachable-set equality claim. The complete affine image, including every
independent residual parameter, supplies the next Picard check. The narrower
Cartesian trajectory endpoint does not silently restrict those parameters.
The time remainder and parameter remainder remain separately evidenced; omitted
columns and fresh residuals are never discarded. Immutable history preserves
all prior fields, original uncertainty and failed-attempt evidence. Only a
complete checked endpoint can be used as a new state.

Fourteen focused tests cover six-step reversible shears, exact algebraic sqrt(2)
coefficients, complete omission, fresh nonlinear residuals, two-step Riccati and
oscillator controls, the narrower-box rejection invariant, empty/invalid and
zero-dimensional inputs, original time-domain guards, graph/scalar exhaustion,
cancellation/retry, final-publication failure, 512-state iterative destruction
with a shared intermediate state, the actual example, and fresh-process replay
from original definitions and requests. The original box-path loss remains a
separate passing adverse witness. The tests establish these cases, not universal
closure of every admitted field, degree, expression or operation depth.

The clean isolated implementation passed full owner and downstream tests,
strict all-feature/all-target Clippy, strict documentation, disabled-feature
checks, the actual example, formatting and WASM library compilation. The final
owner suite reports 153 passes in 19 harness summaries; Hyperphysics reports
83 in 16. Counts are reported harness passes, not distinct semantic obligations.
WASM execution, whole-stack CI, hosted documentation and platform/HIL are not
claimed. Integrated-main checks are recorded separately in main-checks.json;
they do not accept the pre-existing staged extraction or its performance.

Seven source archives were built and verified at implementation commit d97e1a968.
The actual unchanged archived example, final fourteen-test client (including
fresh-process replay), archive-only all-feature Hyperdynamics documentation and
archive dependency-resolution audit passed with Rust 1.95 and stable 1.99.
The final source adds the algebraic acceptance test and removes one stray README
blank line after those archives; all production Rust, manifests, dependencies,
example bytes and substantive README text are identical. No publication, full
21-crate release rerun or complete-stack archive-docs claim is made.

Completed-workload costs compare the certified identity endpoint with width
limits 2+1/M, M=8,32,128. The old box path refines its initial y domain into M
cells; the new path keeps two columns. Both materialize output and retain and
destroy every required proof. COST-CONTRACT.md defines the complete scopes.
Thirty alternating pairs per case and preparation mode run on CPU 8 with the
system allocator, after all known build/test workers finish. One first-use round
is retained but excluded from each process's five summarized rounds. 'Cold'
means program preparation within each workload; it does not mean cold scalar
caches in the summarized rounds. Other host activity is not controlled.

The new path is only about 4% faster at M=8, about 4x at M=32 and about 16x at
M=128. It is 5.7x/6.5x slower in the cold/warm constant-flow control, which gains
no enclosure quality. Linked probe size increases from 3,554,816 to 3,813,408
bytes (+7.27%); ELF text rises from 2,681,158 to 2,889,406 (+7.77%). Named linked
symbol sizes are separately recorded, not universal monomorphized-code bounds.
These finite results support an opt-in strategy, not replacement of the old path
or a general competitive-ODE performance claim.

The separate allocator probe includes initial first-use allocations and reports
retained, peak and post-destruction requested payload. Twenty complete repeated
workloads show no growth after the first, but some cases retain 104, 208 or 312 bytes
after source destruction. Existing small-rational static caches are consistent
with that observation, not precise attribution or proof of leak freedom. The
initial blanket zero-retention assertion failed at 104 bytes and is archived;
it was replaced with explicit lifecycle measurements and the repeat-growth
check. Timing binaries contain none of the allocation instrumentation.

Resource budgets cover the existing structural graph and native dyadic work
units; they do not bound scalar refinement/CPU, coefficient payload, total heap,
RSS or within-scalar cancellation. Requested allocation payload excludes private
tracking headers, allocator overhead and stack. No uniform practical bound is
claimed. Automatic noise-aware horizon control, wider nonlinear/deep-chain cost
qualification, other target platforms and the remaining plan remain open.

Integration uses an alternate index, proves exact reverse application and
compares all pending edits after normalizing only blob IDs/hunk metadata. The
first preflight caught a stray blank line against pending README content before
any main mutation. The isolated cosmetic correction removes that conflict.
All 41 staged paths and both Alumina repository states are preserved. This stage
does not complete a phase or the whole goal, and performs no push/publication.
