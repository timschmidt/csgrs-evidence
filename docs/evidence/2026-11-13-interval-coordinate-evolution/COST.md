# Focused completion and cost evidence

The retained probe is an external consumer of the optional coordinates feature,
with a shared lockfile for both builds. Its registry versions differ from the
workspace lock; both controls use precisely the same external dependency lock.
The baseline is clean 3c9a6a8e; the candidate adds the retained source patch.

Four workloads use one, three, sixteen and sixty-four constant-flow segments.
Native output and all transported source rows agree byte for byte across the
old/new builds. The new owned report agrees with explicit manual transport,
including every native attempt and original identity. Independent analytic
endpoint assertions accompany that equality; Debug agreement alone is not the
semantic oracle. The manual consumer has no atomic aggregate transport budget,
so it is a successful-output cost comparator, not equivalent resource admission.

Prepared-chart timings include request/options/budget creation, integration,
required output transport, independent endpoint assertion, black_box and drop.
They exclude chart construction. The first shuffled short campaign had timing
variation, including an apparent 10.5% native 64-step difference. After compiler
jobs finished, eight randomized rounds repeated the 16/64-step comparisons on
one pinned CPU, with eight warmups and twenty samples of sixteen calls per epoch.
The original unfavorable samples are retained; no speedup is claimed.

Median of eight epoch medians, microseconds per complete call:

| Segments | Old native | New native | Old manual transport | New owned transport |
| --- | ---: | ---: | ---: | ---: |
| 16 | 511.79 | 514.00 | 656.15 | 660.72 |
| 64 | 2123.31 | 2136.34 | 2611.74 | 2662.32 |

These focused measurements are not a competitive validated-dynamics benchmark,
a cold-cache campaign or evidence about arbitrary systems. Native median shifts
are about +0.4%/+0.6%; owned transport is about +0.7%/+1.9% versus manual assembly
on these larger cases, including the new atomic budget boundary. Sample ranges
are in paired-timings.json. The addition is retained for composition and resource
correctness, not as a performance optimization.

All allocation statistics agree for old/new native paths and for manual/owned
complete transport on all four workloads. Every measured complete-result/drop
epoch has zero remaining allocated bytes. Sixteen calls of the three-step
transport allocate 5,440 times, reallocate 912 times, request 1,071,168 bytes and
peak at 16,368 additional live bytes; these measurements do not bound arbitrary
scalar refinement or total process memory.

The external binary includes the new callable API: .text grows from 2,046,279 to
2,056,711 bytes (+10,432). Unstripped debug-bearing file size grows from
43,317,152 to 43,462,464 bytes. Function-address union measurements, complete
section lists, symbols and artifact hashes are retained. No default dependency
or existing production predicate/dispatch order changed.

The three-step exact budget witness uses native graph/scalar work 1,554/937,228
and complete transported work 1,657/1,684,486. Exact-bound success and one-unit-
short late failure both pass. The sixty-four-step combined structural-entry
admission boundary is 524; 523 keeps native completion but fails transport before
output allocation. These are operation accounting units, not total heap bounds.
