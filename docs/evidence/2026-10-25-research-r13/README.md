# R13: forced successor complement opportunity

Disposition: reject the proposed production shortcut for the measured corpus.
No implementation, helper abstraction, API or source instrumentation is retained
in CSGRS. This does not reject the bijection theorem, the existing unary helper,
or the separate H17 exploratory API register. A future source-bound workload
with one unresolved pair would be new evidence.

Owner: Hypercurve selected Boolean boundary successor construction and unary
regularization. Properties P4/P8/P9/P13/P17/P18/P19/P20/P35–P39. A forced
complement requires an already certified selected oriented boundary, equal
incident cardinalities, valid distinct active claims and the same topology
vertex. Equal counts alone are not a proof. The production opportunity was
missing before implementation, so no new abstraction was installed first.

The original 116-test trace used a target directory also used by R12. It is
retained as exploratory evidence and superseded by isolated/. The authoritative
checkout starts at 3cca6a894858c8b98497a3cfe81cff5e17e1a7f2 with the recorded
primary research patch (including the R04 repair and R12 candidate). It owns
/tmp/csgrs-r13-isolated-target; source patch hashes agree before and after the
run. All commands use the workspace lock, release, all features and seed
20261025, with their external time limits recorded. These traces are not timing
or allocation benchmarks.

The private instrument records the binary Boolean caller immediately before
and after tangent-successor reconstruction. It checks distinct active IDs,
matching topology incidence and valid distinct target claims. The
one_remaining field is an opportunity screen, not a published certificate.
Existing geometry assertions and policies are unchanged.

Four groups pass, 186 tests total and three pre-existing ignored stroke tests:

- Boolean, stroke and seeded Boolean fuzz: 65 passes, three ignores; 131
  reconstruction sites, with two missing pairs before every call. Afterwards,
  130 have no missing pairs and one still has two.
- Selected successor fixtures: 62 passes; two sites go from two missing pairs
  to none. These include selected curves, authored subdivisions and contact
  continuation; the full executed test names remain in the log.
- Modeling profiles, mixed exact profiles, enclosures and receipt continuation:
  26 passes; no unresolved binary reconstruction sites.
- PCB receipts, curved outlines, Easyduino import/native materialization and
  DRC handoff, routing, stitching and manufacturing workflows: 33 passes;
  no unresolved binary reconstruction sites. Easyduino includes the strict and
  approximate full-fidelity Nano aggregate comparison, not just parsing.

Across 133 sites and 266 before/after observations, zero have exactly one
unmatched pair. Every observed site has two incoming and two outgoing edges;
all recorded identity/incidence/claim checks pass. None would avoid tangent
construction with a pre-complement, or gain completion with a post-complement.
This supports rejecting the shortcut on these completed workloads; it is not
an exhaustive impossibility theorem about every future high-valence or selected
carrier. The three ignored source-cusp/stroke gates are not claimed as covered.
No performance, memory or package-size benefit is claimed, and no code change
is retained without one.
