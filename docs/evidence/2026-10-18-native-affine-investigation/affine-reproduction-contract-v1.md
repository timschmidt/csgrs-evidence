# Shared affine cancellation acceptance domain

Owning layer: Hyperreal scalar construction. For one defined retained real u
and exact rational a,b, (a+u)-(b+u)=a-b. Recognizing this identity must not require
numeric approximation of u or reconstruct a quadratic normal form on every
comparison. The existing bounded rational-offset recognizer supplies the domain;
its traversal and scale bounds must remain unchanged. Nonmatching bases must
continue through the existing exact/Unknown paths.

Before implementation, run independent zero-refinement order checks using
sqrt(2), sin(2), cos(2), atan(2), and a mixed transcendental/algebraic base. The
shared base cancels by the additive group identity; a separate unequal-base
control uses sqrt(2)<sqrt(3). Unknown is an honest current outcome, but it does
not satisfy this explicitly proposed supported identity. No existing Unknown
case is relabeled wrong, and no new answer is accepted without that identity.

Use the unchanged source and compatible qualified libraries, original 60-second
focused cap, and all inherited storage/memory containment. Preserve failures.
This probe alone does not select or admit a runtime change or an optimization.
