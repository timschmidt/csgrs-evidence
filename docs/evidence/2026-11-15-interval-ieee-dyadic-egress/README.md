## Change and reproduced gap

The public F32Enclosure::from_dyadic and F64Enclosure::from_dyadic constructors return the tightest finite IEEE enclosure of a borrowed validated dyadic interval. Baseline compilation reproduces the missing API. Existing IEEE-to-dyadic conversion can now feed exact arithmetic and then an explicitly directed IEEE projection. This is containment, not source equality when endpoints widen. No native floating arithmetic, infinity sentinel, saturation or partial success is introduced. Unsupported-target rejection and canonical empty remain explicit. Both endpoints share one DyadicBudget; failure leaves the source unchanged. The new implementation reuses the existing private encoder and sign authority without modifying existing arithmetic or predicate bodies.
