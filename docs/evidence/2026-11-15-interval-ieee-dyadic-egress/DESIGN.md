# Directed conversion argument and scope

For a positive nonzero dyadic endpoint x = m * 2^e, let top = e + bit_length(m) - 1. The sum is computed in i128, which accommodates every u64 bit length plus every i32 exponent. Zero is handled separately and both zero signs are canonical.

If top exceeds the largest finite normal exponent, no finite enclosure exists. If top is below the minimum subnormal exponent emin, 0 < x < 2^emin and the tight directed pair is (0, 2^emin), with no shift or allocation. Otherwise the target grid is g = max(emin, top - fraction_bits). This is the spacing at x. Computing floor(x/2^g) retains at most 53 bits. A positive shift discards low mantissa bits; trailing-zero position establishes whether any discarded bit was nonzero. A nonpositive shift is exact and has a result of at most 53 bits. The existing IEEE encoder consumes floor and floor+1 iff the discarded remainder is nonzero. It also detects the carry beyond the largest finite value. Negative endpoints use the existing sign reflection with reversed lower/upper roles.

Thus the pair consists of the adjacent directed IEEE values, or exact equal values, whenever both are finite. For an ordered interval, taking the lower endpoint's floor and upper endpoint's ceiling gives the smallest finite IEEE interval containing it. If either endpoint cannot have a finite pair, the complete interval cannot have a finite enclosure. No endpoint, partial interval, infinity, saturation or guessed result is published on error. Nonempty construction uses the unchanged target qualification guard; empty needs no numeric backend.

The source is borrowed. The IEEE result certifies containment of that source, not equality when rounding widened it. Existing IEEE-to-dyadic conversion reifies the exact resulting enclosure, not the prior tighter source. No implicit authority change or proposal promotion is introduced.

Before limb inspection or temporary allocation, each endpoint reserves three linear stages of max(mantissa bits, fraction_bits+2). Input bit-length metadata is inspected first. The three stages account for mantissa/significand/tail work; the existing budget counts deterministic units and per-stage magnitude limits, not actual cycles, retained heap, cancellation or allocator overhead. No exponent-sized temporary is built. A source may therefore have an extreme exponent yet need only constant temporary storage. The million-bit probe measures requested allocations separately from this accounting. Caller input construction and normalization are outside the operation budget, as for other DyadicInterval methods.

The private extension is compiled only with both dyadic and float-enclosure. No existing arithmetic body, dispatch order, public failure type or dependency declaration changes. Exact tests cover both formats against independent GMP/MPFR conversion, literal boundary values, every exponent field for roundtrip identity, original source immutability, shared-budget failure/retry, serialization and later arithmetic. Float-only native controls are byte-identical before/after. The new allocating WASM consumer is separate from the existing allocation-free float consumer.
