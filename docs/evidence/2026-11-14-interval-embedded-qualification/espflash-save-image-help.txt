Generate a binary application image and save it to a local disk

If the '--merge' option is used, then the bootloader, partition table, and all application segments
will be merged into a single binary file. Otherwise, each segment will be saved as individual
binaries, prefixed with their intended addresses in flash.

Usage: espflash-v4.7.0 save-image [OPTIONS] --chip <CHIP> <IMAGE> <FILE>

Arguments:
  <IMAGE>
          ELF image

  <FILE>
          File name to save the generated image to

Options:
  -f, --flash-freq <FREQ>
          Flash frequency

          Possible values:
          - 12mhz: 12 MHz
          - 15mhz: 15 MHz
          - 16mhz: 16 MHz
          - 20mhz: 20 MHz
          - 24mhz: 24 MHz
          - 26mhz: 26 MHz
          - 30mhz: 30 MHz
          - 40mhz: 40 MHz
          - 48mhz: 48 MHz
          - 60mhz: 60 MHz
          - 80mhz: 80 MHz

  -m, --flash-mode <MODE>
          Flash mode to use

          Possible values:
          - qio:  Quad I/O (4 pins used for address & data)
          - qout: Quad Output (4 pins used for data)
          - dio:  Dual I/O (2 pins used for address & data)
          - dout: Dual Output (2 pins used for data)

  -s, --flash-size <SIZE>
          Flash size of the target

          Possible values:
          - 256kb: 256 KB
          - 512kb: 512 KB
          - 1mb:   1 MB
          - 2mb:   2 MB
          - 4mb:   4 MB
          - 8mb:   8 MB
          - 16mb:  16 MB
          - 32mb:  32 MB
          - 64mb:  64 MB
          - 128mb: 128 MB
          - 256mb: 256 MB

      --chip <CHIP>
          Chip to create an image for

          Possible values:
          - esp32:    ESP32
          - esp32c2:  ESP32-C2, ESP8684
          - esp32c3:  ESP32-C3, ESP8685
          - esp32c5:  ESP32-C5
          - esp32c6:  ESP32-C6
          - esp32c61: ESP32-C61
          - esp32h2:  ESP32-H2
          - esp32h4:  ESP32-H4
          - esp32p4:  ESP32-P4
          - esp32s2:  ESP32-S2
          - esp32s3:  ESP32-S3
          - esp32s31: ESP32-S31

      --merge
          Boolean flag to merge binaries into single binary

      --skip-padding
          Don't pad the image to the flash size

  -x, --xtal-freq <XTAL_FREQ>
          Crystal frequency of the target

          Possible values:
          - 26mhz: 26 MHz
          - 32mhz: 32 MHz
          - 40mhz: 40 MHz
          - 48mhz: 48MHz

      --min-chip-rev <MIN_CHIP_REV>
          Minimum chip revision supported by image, in format: major.minor
          
          [default: 0.0]

      --mmu-page-size <MMU_PAGE_SIZE>
          MMU page size

      --ignore-app-descriptor
          Skip checking whether the app descriptor is present in the image
          
          [alias: --ignore_app_descriptor]

      --format <FORMAT>
          Application image format to use

          Possible values:
          - esp-idf: ESP-IDF application image format
          
          [default: esp-idf]

      --bootloader <FILE>
          Path to a binary ESP-IDF bootloader file

      --partition-table <FILE>
          Path to a CSV file containing partition table

      --partition-table-offset <OFFSET>
          Partition table offset

      --target-app-partition <LABEL>
          Label of target app partition

  -S, --skip-update-check
          Do not check for updates
          
          [env: ESPFLASH_SKIP_UPDATE_CHECK=]

  -h, --help
          Print help (see a summary with '-h')

  -V, --version
          Print version
