# Implementation decisions

Retention is supported by the source-bound qualification, artifact and cost
records linked from README.md. No performance-only claim is made for the API/schema migration.

| Idea | Decision | Reason and evidence obligation |
| --- | --- | --- |
| Preserve selected curve domains | Retained in this finite domain | Required to construct the baseline clipped profile; coefficient consumers request explicit scalar views. |
| Retain a straight sweep of a selected point | Retained in this finite domain | Axial geometry needs the original source field; a fabricated Cartesian origin would lose meaning. |
| Let Hypercurve expose affine point recipes and scalar charts | Retained in this finite domain | Incidence, root authority and correlated point definitions belong to the planar owner; BRep consumes those proofs. |
| Recover a point from an inverse line coordinate | Retained in this finite domain | Requires complete line incidence, inverse-map identities and finite membership; an off-support regression is mandatory. |
| Trace split axial chains during prism admission | Retained in this finite domain | Cold replay must consume the output of edge splitting; topology and forward collinearity are checked, not inferred from endpoints alone. |
| Reuse the existing parameter comparison cascade | Retained in this finite domain | The owner already proves the order of the two overlapping quartic isolators rejected by the old range constructor. |
| Normalize selected endpoints by division | Rejected | Required scalar coefficients may not exist; selected source charts preserve the finite domain directly. |
| Project selected x/y into independent roots | Rejected | Erases common selected authority and can increase elimination work. |
| Serialize recursive field internals or validation flags | Rejected | Persist a checked source recipe; arbitrary recursive fields remain typed unsupported. |
| Add a version-9 compatibility adapter | Rejected | User explicitly authorized a clean API/archive break and prohibited compatibility shims. The evidence comparison only audits two generated artifact sets. |
| Force this profile into STEP rationals | Rejected | The full procedural carrier is unencodable by the current writer; typed body/edge attribution and native recovery are the required boundary. |
| Repair unrelated upstream scalar/certificate gaps | Outside this increment | Integrate supplied upstream corrections and exercise them through BRep archives. The concurrent thread owns broader repairs. |

The frozen baseline consumer binaries and all failed implementation attempts are
retained. New completed workflows have absolute costs; the former selected-domain
rejection is a capability migration, not a matched timing comparison. Comparisons
against the baseline also include the upstream merge and cannot isolate the
feature's performance effect.

The first broad image-proof bypass and opaque reevaluation of native endpoints were rejected by preserved full workflows and archive comparisons. The final implementation restores extrusion-side source proofs and reuses the original represented endpoint facts.
