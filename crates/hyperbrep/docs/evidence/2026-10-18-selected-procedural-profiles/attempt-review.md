# Implementation attempts (in progress)

No feature admission or release claim yet. The latest feature commit remains
`ba7efd793`; `75b4aa7ab` only merges upstream. Every command attempt and source
epoch remains in `attempts.json` and its referenced logs/overlays.

The first complete clipped cap was initially blocked by scalar chart endpoints,
selected vertices, axial edges, side pcurve correspondence and cold whole-image
proofs. The retained representations now cover the original full fixture.
Subsequent composition tests deliberately consume its cold archive:

- Axial splitting first failed because the owner point-location entry point
  rejected retained points before consulting chord incidence. The owner now
  replays support and finite membership. Cold admission then required proving
  axial chains rather than assuming one edge per cap connection. Chains must
  be nonbranching, collinear, forward, unique at both caps and completely
  covered by lateral boundaries.
- Reflection first failed archive encoding of correlated rational point
  expressions, then selected coordinate-map transport. Checked expression
  replay keeps one parameter for both coordinates, proves nonzero denominator,
  and accounts for polynomial arrays in admission limits. Coordinate reflection
  transports the map itself; similarity affine forms retain constant-coordinate
  and original-parameter identities.
- Slab continuation exposed a rational selected fragment without an authored
  restriction view. Scalar-chart conversion now supplies the checked authored
  source/range, and identifies geometric chord charts by carrier, not endpoint
  labels. It does not replace the original selected point fields.
- The selected profile split then exposed overlapping isolators in
  `BezierParameterRange2::try_new`. Its interval-only comparison failed even
  though the same owner's root comparator proved the order. The regression
  retains both exact quartic polynomials/isolators and checks forward, reversed
  and equal ranges. The constructor now uses that existing comparison cascade.

## Artifact preflight: native scalar facts

The preflight completed all 48 prior planar-image artifacts and all 14
selected-planar consumer groups. Six of that cohort's 22 archives changed
312 scalar occurrences (six distinct before/after expression pairs) beyond
the declared schema migration. Exact independent rational-plus-sqrt(2)
reduction proves all these values equal, but 64 stored rational facts and
184 named square-root forms became opaque expressions. Do not waive this as
an incidental format difference. `format-preflight.json` and
`format-preflight-scalar-differences.json` retain the full findings.

An isolated build of the committed upstream merge (before the pending feature)
reproduced all 22 baseline archives byte-for-byte. The copied 1702 input files,
commit, binary and complete consumer run are bound in
`upstream-only-scalar-inputs.json` and `upstream-only-scalar-comparison.json`.
This identifies the pending feature, not upstream integration, as the cause.
BRep construction now prefers the planar owner's already represented endpoint
and its scalar facts, as the prior admitted path did; unavailable points still
retain the spatial source and selected parameter. The owning boundary is BRep
construction under P1–P4/P17–P20/P35/P38. The original artifact comparison is the
failing acceptance check; all fields except the declared header/chart migration
must remain preserved. This correction is still a candidate until rerun.

original narrow comparator rejected the two finite-pole subcurve archives.

costs sequentially. Supplemental evidence scripts bind their own input hashes;
they do not replace the original failed command or alter qualified source.
