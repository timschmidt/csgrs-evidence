# Follow-up cost investigation

This is a source-guided experiment proposal, not a measured causal attribution
or an accepted optimization. The complete campaign retains the costs of the
current feature extension. The pending upstream merge comes first.

The observed circle-document and supplied-pcurve increases include allocation
and archive-size growth. Rational reciprocal `atan` normalization changes the
retained angle expression; the archive migration review must account for those
bytes independently of latency. A smaller or less complete output cannot serve
as a successful comparison for the original workload.

BREP's [`ArenaModelBuilder::solid`](../../../src/topology/builder.rs) already
computes whole-solid cylinder and other analytic certificates during admission.
It currently records no retained certificate for the ordinary builder path.
`finish` then attempts prism certification and independently derives cylinder
certificates again. The newly admitted plane/cylinder prism path can therefore
add profile construction and proof work even when a native cylinder certificate
is available. Signed curved-prism orientation also derives a prism certificate
before later immutable-model queries. These are concrete sites to investigate;
their contribution to the observed slowdown has not been isolated.

Before changing this path, reproduce the cost and check whether an already
validated, immutable solid can retain its exact native certificate within the
same builder transaction. Preserve ordinary ownership checks, all cap and side
image proofs, orientation, holes, void nesting and replay admission. A certificate
must bind the actual source geometry and remain valid after every allowed builder
operation. Do not add a process-global cache, skip validation, infer a cylinder
from bounds, or select an older representation solely to match old bytes.

Measure the isolated proposal against this feature baseline, then repeat the
complete preserved correctness and cost corpora. Keep the same STEP inputs,
iteration counts, output materialization and exact receipts. In particular,
preserve the two-semicircle annulus, whole inward-shell rejection, imported
half-cylinder and bore recuts, split/replay, strict near-offset controls and
all existing cylinder/loft/spline cases. Typed uncertainty and exhaustion remain
distinct. A favorable focused run does not discharge the other adverse rows or
the historical archive, spline, arc and pcurve performance gates.

Surrounding scalar performance changes remain upstream-owned unless a reproduced
BREP contract makes an owning-layer repair necessary. Do not undo the principal
angle proof needed by the original rationally rotated prism continuation or
duplicate that identity in a BREP caller.
