# Exact planar lift contract

A source curve C(t), independent vectors u,v and an origin o define
L(s)=o+u*C_x(a+(b-a)s)+v*C_y(a+(b-a)s), 0<=s<=1. The strict constructor proves
(u cross v)^2>0, a!=b, and source membership at both endpoints. This is a
definition, not a proof that an arbitrary source is finite or simple throughout
its interval. Hypercurve owns the complete source, its domain failures,
procedural regularity and selected-parameter identity. Face admission separately
requires the whole simple-loop proof below. No offset equation is copied into
production BRep code. Scalar point evaluation explicitly asks the owner for the
exact point when a lazy view has no stored coordinates.

Derivative order k uses the owner's derivative and the chain factor (b-a)^k.
Bounds lift all four corners of the conservative source AABB; they need not be
tight after restriction. Point location first proves plane membership, projects
through the injective frame, asks the owner for all preimages and maps/filters
those parameters into the spatial unit interval. A reversed chart reverses the
ordered roots. Extrusion point location uses the same transverse plane formula
as native line/spline generators, followed by the complete profile inverse query.

Reversal/subdivision change the chart, not the source. A nonsingular affine
spatial transform changes o,u,v. A nonuniform image is not reinterpreted as a
new constant-distance offset. Whole edge/pcurve admission compares complete
source definitions in the explicit chart and proves any needed plane-frame
similarity. The same definition proof handles translated extrusion profiles.
It never promotes matching endpoints into complete image agreement.

Procedural wire admission calls Hypercurve's whole original simple-loop proof:
its arrangement must retain every carrier and prove a single simple cycle.
Winding proves orientation even without a represented area integral. The
existing cap pairing, shared side topology and transverse translation certify
the product shell. Generic adjacency also uses directed parameter endpoints,
not the ascending enclosing domain. This fixes the original top-cap replay,
whose arch traverses source parameter 1 to 0.

Raw records encode definitions, not authority. Strict replay validates source,
frame, chart and complete topology. Roots/charts and authored planar sources
load before detached spatial sources and model point images. No backward edge
into spatial sources exists. Quadratic/cubic native pcurve tags preserve the
original polynomial family; all inline sources charge metadata before scalars.
A forged frame keeps exact endpoint coordinates while changing the interior;
replay must reject it. Collapsed frames, invalid chart intervals and invalid
selected references also fail without publishing a model.

Numerical certification describes the current exact definition. Topological
validity is separately established by model admission. Native replay preserves
that definition; it does not certify an earlier approximate source intent or
persist a full feature history. Missing area/volume or STEP encoding is a typed
query failure, not invalid topology or an empty successful model.
