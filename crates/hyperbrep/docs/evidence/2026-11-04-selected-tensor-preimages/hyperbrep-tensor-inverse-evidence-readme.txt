Owners: Hypercurve complete point preimages of rational maps and selected branch fields; HyperBRep spatial validation, chart transport, topology edits and exact native replay. P6/P14/P15/P17/P18/P19/P20. Native archive remains version 17.

The original public witness generates the x=0 section of z=x^2+y^2 over [-1,1]^2. An independently authored rational parabola gives (0,2a-1,(2a-1)^2), where 32a^5-2a-1=0 and a is the selected unit root. The generated point is proved exactly equal before inverse location. The previous implementation reports UnsupportedParameterLocation; the new inverse recovers exactly a without coordinate materialization. It preserves reversed and restricted source charts and an invertible reflected shear/scale. A face split supplies two uses of this TensorImage edge; the recovered parameter splits both, survives cold and fresh-process replay, supports another selected split and a reflected nonuniform affine model replay.

Curve2::rational_image_point_locations queries map(source(t)) without fitting or publishing a replacement curve. Native homogeneous spans use exact substitution and the existing selected polynomial coefficient-field solver. Selected polynomial branches reuse coefficient-field section resultants, original branch ranks, closed active trims and exact point equations. Every finite visit survives noninjective maps. Original source and map denominators are checked at candidates even when factors cancel. An identically zero global map denominator is invalid. Constant-image claims need zero tangent-derivative proof plus nonzero-denominator coverage; a constant projection alone is not an entire spatial inverse. BRep checks all three spatial coordinates at each candidate and transports authored knot/source charts.

Acceptance includes folded branches with two selected preimages; independent rational target queries; nonrational source fibers and wrong branches; constant algebraic images; original removable poles; circular rational charts with three visits and seam deduplication; native spline knot maps; exact 2^-60 third-coordinate rejection; and budget refusal followed by a larger retry under strict and approximate policies. The two source chart locations remain available.
