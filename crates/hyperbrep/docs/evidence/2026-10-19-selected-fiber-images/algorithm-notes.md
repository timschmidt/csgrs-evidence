# Feasibility notes

Primary references consulted 2026-10-19:

- [CGAL algebraic kernel, 6.2.1 reference](https://doc.cgal.org/latest/Algebraic_kernel_d/classCGAL_1_1Algebraic__kernel__d__2.html) describes a selected first coordinate plus curve/fiber ordinal, without storing an independent univariate second coordinate. It identifies extracting that second coordinate as expensive. This corroborates retaining correlated point authority; it is not an independent oracle or a measured performance comparison. The earlier 5.1 URL was unavailable during the final recheck; this official reference was retrieved successfully.
- [Bounds for polynomials on algebraic numbers and application to curve topology](https://arxiv.org/abs/1807.10622), Diatta et al., version 4 (2021): the abstract describes a certified topology algorithm without changing coordinates, using amortized algebraic-root bounds and local critical-point analysis. It is a later separation/work-bound research lead; no claimed complexity bound is transferred to this implementation.
- [Exact Symbolic-Numeric Computation of Planar Algebraic Curves](https://arxiv.org/abs/1201.1548), Berberich et al. (2012): the abstract describes certified bivariate isolation and curve-topology subroutines without a generic-position requirement. This is a later arrangement research lead. Reading its abstract does not establish that its algorithm has been implemented here.

Local construction argument (our inference): specialize F,N,D into the existing ordered coefficient field Q(alpha). Norm_y(D*z-N) over its finite F quotient yields a polynomial in z over that field. It enumerates images and may include other local conjugates; it does not select a point. Saturated common factors where N=D=0 must be kept explicit. A strictly certified nonzero D at the selected beta and a shrinking outward image enclosure, containing exactly one norm root, identify N(alpha,beta)/D(alpha,beta). No global norm through alpha or unrelated coordinate reconstruction is required. Source point and affine recipe remain the replay authority for the public affine extraction. Total work, coefficient-growth and heap bounds are not proved by the algebraic construction.
