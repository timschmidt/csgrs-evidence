# Selected surface patches

The owner is HyperBRep construction, spatial boundary images and native archive
encoding. Hypercurve continues to own curve definitions, selected roots and
parameters, correlated planar points, simplicity, nesting and affine chart
arithmetic. Properties P1, P3, P8, P9, P11, P12, P14, P17–P20, P25–P27 and
P35–P39 apply; this is a finite extension, not full satisfaction of those gates.

## Public contract

`builder::planar_face(outer, holes, origin, u, v)` accepts supported retained
procedural parallels and source restrictions with selected endpoints. The
existing complete simplicity, separation and nesting checks determine the
material region. Curves retain an injective authored affine plane frame;
vertices retain selected source points when scalar coordinates are unavailable.
No display approximation or caller-supplied image certificate is introduced.

`builder::extrusion_patch(profile, direction, v_start, v_end)` accepts a selected
profile domain and a strictly ordered authored finite extrusion interval.
For S(u,v) = P(u) + vD, horizontal edges keep the profile's u chart; vertical
edges retain their selected origins and use t = (v-v_start)/(v_end-v_start).
The ordinary builder validates every complete coordinate boundary image. It
returns a `SheetSet` containing an open shell with one face; it establishes no general shell embedding
or solid interior claim. Native endpoint domains keep their existing path.

Both public builders use strict predicate authority and preserve typed geometry,
construction and resource failures. Selected endpoints retain source and
selection identity. Reversal, supported affine transforms, native replay and
supported topology splits remain downstream operations. Selected angular
revolution endpoints and independent selected axial parameters remain outside
this extension.

## Archive correction

A nonorthogonal planar-face fixture reproduced expression growth on unchanged
baseline eaa0cae54442e0e5c311c3ad917a489e0319892e. The original and replayed
archives had unchanged vertices/topology but different planar pcurve endpoint
expressions. Encoding now preserves pcurve definitions unless native analytic
arc endpoint canonicalization actually replaces an incident vertex's coordinate
recipe. Existing circular/elliptic endpoint canonicalization remains.

This changes some first-export scalar expression encodings while retaining
schema version 10. It is a correctness/representation correction, not a
byte-preserving optimization. Any observed encoding migration must be audited
by field and exact scalar equality, separately from independent geometry
assertions and deterministic fresh/cold replay. No compatibility reader is added.

## Acceptance and limits

The seven shared groups test public construction, selected root identity,
reversal/reflection/shear, profile and connector splits, nonorthogonal frames,
holes, exact area and linear forms, independent profile samples, retained plane
contacts, 1/10^12 classification offsets, forged image maps/displacements,
strict→approximate→strict scopes, zero work allowance and recovery. Earlier
complete workflows and failures remain controls; counts alone are not proof
of their intended sets.

OperationContext accounts for selected refinement/promotion work. It does not
bound aggregate scalar work, coefficient growth, retained heap or cancellation.
External timeouts contain validation and measurement; measured allocations and
process RSS do not establish internal bounds. Source-path Rust and actual WASM
execution do not establish installed packages, MSRV or production bindings.
Fuzz-target compilation is not a runtime campaign. Coverage and executable
formal-proof targets, general arrangements/intersections, selected revolution
patches, arbitrary shell embedding and the full CAD roadmap remain open.
