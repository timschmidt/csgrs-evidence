# Retained polynomial branches and points

The owner is Hypercurve. Hypersolve already supplies the exact complete projection, event fibers and arc incidence; BRep consumes planar point definitions through its existing selected-parameter archive. This increment adds no filled-region carrier and no independent scalar solver.

For each open slab of the admitted rational zero set F(x,y)=0, the solver proves that all ordered simple fiber roots continue to the adjacent event fibers. Curve construction retains one native branch per arc, its slab/root ordinals, the shared immutable topology, the increasing source x-domain, and both selected event points. No graph field is publicly mutable. Every event root not incident to an arc is retained as an isolated point; this is set topology, not multiplicity or winding.

Point evaluation first certifies membership in the retained range. Endpoint queries reuse their exact selected point. An interior query isolates the complete source fiber at the supplied rational or algebraic x and checks its root count against the slab census before selecting the stored ordinal. Each point stores both the base parameter and its fiber authority. The existing selected-fiber refiner independently replays singleton evidence; a serialized distinct-root count is not a certificate. Real-valued interval midpoints never become point coordinates.

Splitting retains the source chart and authority and certifies the new endpoint. Reversal changes traversal, not the equation or chart. Similarities compose one exact image map; point images use the existing retained similarity carrier, including its policy checks. The entire source rectangle transformed by its corner images is a conservative branch box. These broad boxes are not claimed tight. Coordinate comparison and affine/circle sign queries use the retained fiber; representationally narrower consumers keep typed blockers.

The additive BRep planar-point record stores equation coefficients, the source parameter DAG reference, a fiber interval and an optional exact witness. Import reconstructs the selected base and replays the fiber singleton through Hypercurve. It serializes neither certainty nor a trusted root-count flag. Whole implicit-curve archives, tensor surface images and both intersection pcurves are not implemented by that record.

The acceptance recipes use independently known circle, cubic-root, node, cusp, isolated-point and empty-set geometry. They exercise selected event endpoints, 1e-12 loops, repeated/reversed subdivision, image evaluation, affine invariants, strict/approximate/strict requests, forged selectors, resource refusal and recovery. The original BRep section probe continues to assert complete success and remains a failing frontier case. Its failure is not turned into a passing negative capability test.

Resource controls remain partial: fiber depth/refinement and existing shared work units do not bound total arithmetic, coefficient bits, retained heap or cancellation latency. There is no new mutable global cache. Branches share their source; selected fibers reuse the existing authority/refinement caches. Restrictions and transforms do not build source-history chains. The finite measurements and tests do not establish formal verification, general arrangements, production bindings, package release readiness, or the complete pre-push matrix.

The point carrier uses shared indirection, matching the existing native selected-point handles. A rejected inline attempt enlarged CurvePoint2 from 16 to 56 bytes and its public definition from 360 to 400 bytes. The retained implementation restores 16/360 bytes on the measured x86_64 target; the measured Curve2 handle remains 8 bytes. This is target-specific layout evidence, not an ABI guarantee.

Public archive admission was separately reproduced failing on the new tag after the direct point decoder passed. The metadata visitor now recognizes the same PolynomialFiber record and charges both stored axis degrees plus all coefficient and row entries before scalar decoding. A shared public model recipe constructs a retained chord endpoint, replays the entire untrusted model, reverses its curve, checks exact bytes and point identity, rejects forged witnesses and tests exact resource refusal/recovery. It also supplies malformed scalar data behind over-limit metadata to verify that scalar construction is not required for refusal.
