# Decisions

| Idea | Decision and scope |
| --- | --- |
| Borrow the procedural definition from Hypercurve | Kept: the curve owner exposes direct and analytic selected-fiber definitions without duplicating offset mathematics. |
| Reuse existing selected-root graphs | Kept: preserve polynomial/isolator authority and flattened charts, with shared references and strict replay. |
| Store homogeneous rational controls | Kept: zero-weight controls must not be forced through an affine-control view. |
| Rebuild regularity through the existing constructor | Already supplied by Hypercurve; reused instead of adding a BRep solver or accepting serialized proof flags. |
| Charge inline source metadata before decoding | Kept: new records, control counts and degrees join the existing archive admission budget. |
| Force every zero-budget replay to exhaust | Rejected test assumption: sufficient exact certificates can require no instrumented refinement. Preserve cheap success and test actual cusp-isolation exhaustion separately. |
| Treat subdivision as always retaining the direct fragment variant | Rejected: the public subdivision path retains an analytic selected-fiber carrier; the shared structural view must include it. |
| Replace the offset by fitted rational curves or chords | Rejected: that changes the authoritative geometry. No approximate representation is introduced. |
| Infer a valid spatial face from pcurve replay | Rejected: complete spatial correspondence and shell admission remain separate work. |
| Intern all procedural supports in a new archive graph | Deferred: the finite increment stores definitions inline and shares selectors. Any new support interning needs measured complete workloads and an explicit representation decision. |
| Mesh/tessellation or STEP changes for this handoff | Architecture-inapplicable: this handoff is native pcurve persistence. Their contracts remain independent. |

This is a capability extension. The cost records retain prior completed work
and absolute new-workflow costs; they do not compare a former error with a new
success as a speedup. Earlier adverse costs remain open.
